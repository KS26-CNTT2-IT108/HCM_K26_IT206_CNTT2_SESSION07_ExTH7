3. Phân tích lỗi chương trình ban đầu
a, b, c và avg đều là int, nên (a + b + c) / 3 là chia nguyên: C cắt bỏ phần thập phân.
Với 7, 8, 9: tổng 24, 24 / 3 = 8 đúng giá trị. Chỉ khác ở chỗ in 8 chứ không phải 8.0, vì %d chỉ in số nguyên.
Lỗi thật sự lộ ra khi tổng không chia hết cho 3: 7, 8, 8 có tổng 23, 23 / 3 = 7 thay vì 7.67.
Chỉ đổi avg sang float là chưa đủ: phép chia vẫn tính bằng số nguyên trước rồi mới gán.
printf dùng %d cho số thực sẽ in sai, phải dùng %f.

4. Code sau khi tự sửa
c
#include <stdio.h>

int main() {
    int a, b, c;
    float avg;

    printf("Nhap 3 diem: ");
    scanf("%d%d%d", &a, &b, &c);

    avg = (a + b + c) / 3.0;   // 3.0 là số thực nên phép chia là chia số thực

    printf("Diem trung binh: %.2f\n", avg);

    return 0;
}

Kiểm tra: nhập 7 8 9 → 8.00; nhập 7 8 8 → 7.67.

5. Chia nguyên và chia số thực
	Chia nguyên	Chia số thực
Khi nào xảy ra	Cả hai toán hạng đều là int	Ít nhất một toán hạng là float/double
Kết quả	Bỏ phần thập phân	Giữ phần thập phân
Ví dụ	5 / 2 = 2	5.0 / 2 = 2.5
In bằng	%d	%f
int lưu số nguyên, float lưu số có phần thập phân.
Kiểu của kết quả phụ thuộc kiểu của các toán hạng, không phụ thuộc kiểu biến nhận kết quả.

6. Ví dụ mới chứng minh đã hiểu
Chia 10 viên kẹo cho 4 bạn:

10 / 4 (int) = 2: mỗi bạn được 2 viên nguyên.
10 / 4.0 = 2.5: chia chính xác, kể cả phần lẻ.
10 % 4 = 2: số kẹo còn dư.
c
int keo = 10, ban = 4;
printf("%d\n", keo / ban);       // 2
printf("%.1f\n", kẹo / 4.0);     // 2.5
